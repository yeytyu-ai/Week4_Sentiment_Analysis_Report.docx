
# Week 4 Project Summary

## Project Title
Text Analytics and Sentiment Analysis

## Domain
Data Analytics and Natural Language Processing

## Programming Language
Python

## Project Description
This project analyses beauty and wellness customer reviews using basic text preprocessing and dictionary-based sentiment analysis.

## Main Features
- Text cleaning and preprocessing
- Word tokenization
- Positive, negative, and neutral sentiment classification
- Sentiment percentage calculation
- Sentiment distribution visualization
- Word cloud generation
- CSV output for analysed reviews
- Basic unit testing

## Input
A CSV file containing customer reviews.

## Output
A CSV file containing reviews and their predicted sentiment labels, along with visualizations when the relevant scripts are run.

## Learning Outcomes
This project provides practice in Python functions, file handling, CSV processing, text cleaning, basic sentiment classification, data visualization, and unit testing.

## Limitation
The sentiment classifier uses a simple word dictionary. It may not correctly understand sarcasm, context, or complex sentences.
