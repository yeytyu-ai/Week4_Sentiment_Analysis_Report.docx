# Week4_Sentiment_Analysis_Report.docx

## How to Run the Project

### 1. Install Python
Install Python 3 on your computer or use a suitable online Python environment.

### 2. Install Dependencies
Run the following command:

```bash
pip install -r requirements.txt
```

### 3. Run Sentiment Analysis
Keep `sample_reviews.csv` and the Python files in the same folder. Run:

```bash
python analyze_reviews.py
```

### 4. Generate Visualizations
Run the following commands separately:

```bash
python sentiment_visualization.py
python wordcloud_visualization.py
```

### Output
The analysis script generates `sentiment_analysis_results.csv`.
The visualization scripts save the sentiment distribution chart and word cloud as image files.
